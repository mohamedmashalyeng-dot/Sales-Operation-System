### Request path fixed

- `/api/emails` now accepts both `date_filter` and `date_field`.
- The frontend now sends `date_filter` to match the browser request shape.
- `date_filter=received` and `date_field=received` resolve to the same normalized filter.
- If `date_filter` is an ISO day (`YYYY-MM-DD`), it is treated as the day filter.
- Current frontend build id is `20261001-inbox-local-rootcause`.
- `index.html` and `sw.js` now reference `/app.js?v=20261001-inbox-local-rootcause`.
- On localhost, `app.js` unregisters service workers and clears `pathway-*` caches; `sw.js` also ignores localhost and all `/api/*` requests.

### Regression safeguards

```env
EMAIL_LIST_STATEMENT_TIMEOUT_MS=5000
```

Inbox list queries now run with PostgreSQL `statement_timeout` and node-postgres
`query_timeout`. A stuck list request should fail quickly instead of hanging for ~60 seconds.

This timeout is a guardrail, not the root-cause explanation. The normal exact request remains on
the indexed fast path.

## Inbox SQL

Current Inbox Unanswered query shape:

```sql
select jsonb_build_object(
  'id', id,
  'lead_id', coalesce(lead_id, ''),
  'first_name', coalesce(first_name, ''),
  'last_name', coalesce(last_name, ''),
  'email', coalesce(email, ''),
  'from', coalesce(email, ''),
  'subject', coalesce(subject, '(No subject)'),
  'owner', coalesce(owner, ''),
  'date', received_at,
  'received_at', received_at,
  'created_at', received_at,
  'direction', coalesce(data->>'direction', 'inbound'),
  'response_at', response_at,
  'response_note', coalesce(response_note, ''),
  'due_at', due_at,
  'gmail_message_id', coalesce(gmail_message_id, ''),
  'gmail_thread_id', coalesce(data->>'gmail_thread_id', ''),
  'gmail_labels', coalesce(data->'gmail_labels', '[]'::jsonb),
  'gmail_label_names', coalesce(data->'gmail_label_names', '[]'::jsonb),
  'dashboard_folder', coalesce(data->>'dashboard_folder', ''),
  'trashed_at', coalesce(data->>'trashed_at', ''),
  'trash_reason', coalesce(data->>'trash_reason', ''),
  'is_read', coalesce(data->'is_read', 'true'::jsonb),
  'snippet', left(coalesce(data->>'snippet', ''), 260)
) as data
from app_emails
where not (trash condition)
  and not outbound
  and not configured internal mailbox/domain
  and response_at is null
order by received_at desc nulls last, id desc
limit 51
```

The hot list query does not select message body, HTML, raw payloads, attachments, or full thread content.

## Inbox index and EXPLAIN

Index used:

```sql
create index concurrently if not exists app_emails_unanswered_page_idx
on app_emails (received_at desc nulls last, id desc)
where not trash and not outbound and response_at is null
```
